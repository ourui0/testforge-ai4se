# TestForge Harness 设计记录

本设计于 2026-08-04 通过 Superpowers `brainstorming` 流程形成并经用户批准。

完整、规范性的设计规约位于项目根目录 [`SPEC.md`](../../../SPEC.md)。后续实现计划、验收、评审和需求变更均以 `SPEC.md` 为唯一事实来源。本记录用于满足 Superpowers 的设计文档路径约定并保留设计来源。

## 已批准的核心设计

- 面向 Python + pytest，由用户指定单个目标文件或模块；
- 状态机驱动的单任务、单候选、有限轮次反馈循环；
- pytest、coverage.py 与 mutmut 提供确定性反馈；
- 平衡质量门槛：无回归，且变异得分或分支覆盖率相对基线提升；
- 反馈闭环为主要贡献，Docker 沙箱、文件围栏与审批机制提供治理；
- 生产代码默认只读，重构和最终写回均需绑定补丁哈希的人工批准；
- 供应商无关 LLM 接口，首个真实适配器为 OpenAI，并提供脚本化 mock LLM；
- 项目级结构化记忆，不使用 RAG，不保存完整源码和凭据；
- CLI 核心 + 本地 WebUI；公网 WebUI只运行内置示例和 mock LLM；
- PyPI 包与 Docker 镜像分发。

## 设计边界

第一版不支持多语言、集成测试、端到端测试、并行候选、任意 Shell、线上不可信代码执行、多用户协作或自动写回。
